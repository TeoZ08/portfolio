# START HERE

## O que estamos construindo

Um pequeno mundo 3D estilizado, explorável e vivo, que contém um portfólio profissional sem se comportar como um template de portfólio.

A experiência utiliza lugares como linguagem biográfica:

- **Casa**: dimensão pessoal.
- **Universidade**: formação e trabalhos acadêmicos.
- **Ateliê/Laboratório**: projetos pessoais, experimentos e conteúdo técnico.
- **Espaço comunitário**: extensão universitária e atividades com outras pessoas.
- **Dojo**: prática marcial.
- **Campo**: hub e espaço de respiro.
- **Bosque**: experimentação, segredos e elementos menos profissionais.
- **Colina**: encerramento espacial e horizonte futuro.

O visitante pode explorar livremente, mas conteúdo profissional importante também deve ficar disponível por um modo direto.

## O que não estamos construindo

- um currículo gamificado;
- um RPG sobre programação;
- um clone de Stardew Valley;
- um clone de Minecraft;
- uma demo de Three.js;
- um cenário 3D atrás de cards tradicionais;
- um portfólio cyberpunk;
- uma interface baseada em terminal;
- uma coleção de skills com porcentagens.

## Primeiro objetivo de produção

Não construir o mundo inteiro.

Primeiro:
1. fundação técnica;
2. playground de player/câmera;
3. sistema de interação;
4. pequeno protótipo ambiental;
5. vertical slice: **chegada → campo → casa → quarto → computador → primeiro projeto**.

Somente depois de o vertical slice atingir a identidade desejada o restante do mundo deve ser produzido.
