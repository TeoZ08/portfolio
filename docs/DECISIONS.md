# Decisões fechadas

## Produto

- portfólio-mundo, não homepage;
- exploração opcional;
- conteúdo profissional disponível diretamente;
- mundo contemporâneo e pessoal;
- laboratório e oficina unificados em Ateliê/Laboratório.

## Arte

- 3D estilizado;
- diorama ilustrado;
- personagem visível;
- câmera 3/4 elevada;
- materiais foscos;
- paleta natural;
- sem voxel/pixel/cyberpunk.

## Navegação

- exploração física;
- quase nenhum HUD;
- `Esc` como rota de conveniência;
- mobile adaptado em vez de desktop espremido.

## Técnica

- Next.js + React + TypeScript;
- React Three Fiber / Three.js;
- Zustand;
- Rapier;
- GSAP para sequências;
- Motion para UI;
- MDX;
- Zod;
- GLB/glTF;
- Blender para assets;
- localStorage versionado para persistência inicial.

## Produção

- começar em projeto separado do portfólio atual;
- primeiro construir foundation/playground;
- vertical slice obrigatório antes das demais regiões;
- Codex não toma decisões de produto.
