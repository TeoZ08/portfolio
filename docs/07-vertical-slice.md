# v0.7 — Vertical Slice Specification

## Percurso

**Prólogo → Chegada → Campo → Casa → Quarto → Computador → Jarvis Acadêmico → retorno ao quarto**

## O que precisa provar

1. Explorar é agradável.
2. O ambiente parece pessoal.
3. O mundo comunica sem depender de “Sobre”.
4. Conteúdo profissional sério nasce naturalmente da experiência.
5. WebGL, HTML, estado e câmera convivem sem parecer demo técnica.

## Duração

- caminho principal: 3–6 minutos;
- exploração opcional: ~8 minutos;
- acesso por modo direto ao projeto: menos de 2 minutos.

## Prólogo

- 0:00–0:03: tela escura + áudio;
- 0:03–0:15: viagem pela janela;
- 0:15–0:20: desaceleração;
- 0:20–0:27: desembarque;
- ~0:27: entrega de controle.

Durante a viagem, uma mochila ou objeto pode mostrar discretamente `M. L. Scotti`.

## Campo

Primeiro panorama deve mostrar:
- personagem;
- estrada;
- campo;
- casa;
- landmark/árvore;
- profundidade;
- céu.

Sem hero, navbar ou card.

Primeira interação opcional:
- sentar em banco/pedra;
- câmera muda;
- UI some;
- nada precisa “recompensar” o jogador.

## Casa

A casa fica progressivamente mais presente.

Entrada:
- `E · entrar`;
- personagem alinha;
- abre porta;
- atravessa;
- câmera acompanha;
- áudio externo sofre crossfade.

## Quarto

Elementos mínimos no blockout:
- janela;
- estante;
- quadro;
- cadeira;
- mesa;
- monitor;
- teclado;
- caderno;
- fones.

O quarto precisa parecer usado, não showroom.

## Computador

Sequência:
1. aproximação;
2. `E · usar`;
3. alinhamento;
4. sentar;
5. câmera no monitor;
6. UI HTML entra.

Desktop inicial:
- Projetos;
- Faculdade;
- Notas;
- Terminal.

Primeiro projeto funcional:
**Jarvis Acadêmico**.

## Case study

Estrutura:
- identificação;
- contexto;
- objetivo;
- participação;
- arquitetura;
- implementação;
- resultado;
- links/mídia.

Conteúdo textual deve ser factual e evitar slogans.

## Retorno

Fechar case study → janela → desktop → sair do computador → câmera recua → personagem levanta → controle volta.

A iluminação externa pode ter mudado discretamente para mostrar passagem de tempo.

## Menu direto

`Esc`:
- Continuar
- Projetos
- Sobre
- Contato
- Configurações

## Mobile

No slice já deve existir:
- toque para destino ou controle equivalente validado;
- arrastar câmera;
- botão contextual;
- UI do computador adaptada.

## Gates

Não avançar para novas regiões se:
- parecer template;
- parecer demo de Three.js;
- parecer clone de Stardew;
- depender de asset pack genérico;
- puder pertencer a qualquer desenvolvedor sem mudança relevante.
