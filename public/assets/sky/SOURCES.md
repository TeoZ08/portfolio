# Original sky panorama — GOAL 12

`painted-cloud-panorama.webp`: 2048 × 1024 RGBA, 76,622 bytes. Original deterministic spherical noise generated by `scripts/generate-sky-panorama.mjs` on 2026-10-10. No source image, HDRI, Minecraft/Mojang texture, downloaded model or third-party artwork was used. Licensed CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ .

The local equirectangular cloud layer is sampled in a fixed world direction inside the sky dome. Gradient, cloud tint, sun and fog are linked to the existing time-of-day presets. Longitude is seamless because both edge columns sample the same XYZ direction. No sun is baked into the image; the shader draws the single disc aligned with the directional light. Procedural clouds are the failed-load fallback.

Existing Hanok/Kenney/Poly Haven asset provenance remains in `/assets/songahm/SOURCES.md`; their source files are preserved. No new network dependency or project package was added.

`/assets/terrain/regional-soil-mask.png`: original 256 × 256 scalar splat mask generated offline by `scripts/generate-soil-mask.mjs` from the existing regional layout and routes. 49,857 bytes, CC0 1.0. The runtime reads it in linear data space with clamp wrapping. Baking avoids repeated route-distance work on mobile. It is regenerated when routes/biomes change.
